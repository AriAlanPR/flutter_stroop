## Enlaces Rápidos y Comandos Frecuentes

- **Ejecutar pruebas automatizadas**:
  ```bash
  flutter test
  ```
- **Generar iconos de aplicación**:
  ```bash
  dart run flutter_launcher_icons
  ```
- **Generar pantalla de bienvenida nativa**:
  ```bash
  dart run flutter_native_splash:create
  ```
